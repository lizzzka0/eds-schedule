# EDS Schedule

Сервис электронного расписания занятий
Екатеринбургской духовной семинарии.

Курсовой проект по дисциплине
«Объектно-ориентированное программирование».

## Стек технологий

- Frontend: React, TypeScript, Vite
- Backend: NestJS, TypeScript
- База данных: PostgreSQL (планируется)
- ORM: Prisma (планируется)
- Тестирование: Jest

## Структура

- `frontend/` — пользовательская часть
- `backend/` — серверная часть и REST API

## Запуск frontend

Из папки frontend:

    npm install
    npm run dev

## Запуск backend

Из папки backend:

    npm install
    npm run start:dev

## Тестирование backend

Из папки backend:

    npm test

## Статус

Создана первоначальная структура проекта.
Frontend и backend запускаются локально.
Первоначальный модульный тест пройден.
